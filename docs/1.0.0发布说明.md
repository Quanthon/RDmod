# Rainbow Dash 1.0.0

发布文件：`dist/RainbowDash-1.0.0.zip`，校验文件：`dist/RainbowDash-1.0.0.zip.sha256`。

## 安装与兼容

依赖 `STS2-RitsuLib`，发布包不包含该依赖。请单独安装 RitsuLib。
本地安装时将 ZIP 内三个文件解压到游戏目录 `mods/RDmod/`。
工坊内容目录使用 ZIP 内的 RDmod.dll、RDmod.pck、RDmod.json；本次没有上传工坊。

本次验证环境为游戏 v0.111.0、RitsuLib 0.5.20。旧版游戏、联机和工坊订阅安装未在本次验收。
早期测试版本中部分弃用卡牌 ID 已移除，含这些卡牌的旧存档不保证兼容；1.0.0 建议新开一局。

## 本次发布准备

- 版本由 0.3.0 推进至 1.0.0，重新构建 Release DLL 和 PCK。
- 修复导出失败被当作成功的问题；失败时清理残留 PCK，阻止 ZIP 生成并恢复版本号。
- 修复版本号格式校验，拒绝非法分隔符和数字前导零。
- 闪电苹果：补齐基础/升级版仅转换手牌状态牌、其他牌堆不变及无状态牌的行为验收。
- 凌波微步：补齐零蓄力、蓄力耗尽、满手停止、100次上限及重复预览的行为验收。
- 打包工具10项测试通过；94张卡牌映射无缺项；ZIP三文件、CRC与SHA256已检查。

详细日志保存在 `outputs/release-review/`。此次未调整卡牌数值、效果或设计工作簿。
